# Devpost Submission

## Project name

The Cortex

## Elevator pitch

Thoughts disappear in seconds, taking ideas, insights, and connections with them. The Cortex captures fragmented thinking and transforms it into an evolving, searchable digital mind.

## Short description

The Cortex is an interactive algorithmic laboratory for capturing, connecting, and exploring human thought. It turns isolated ideas into an inspectable memory graph, allowing users to watch information move through perception, memory, connection, reasoning, and visualization stages.

## Built with

Next.js, React, TypeScript, JavaScript, HTML5, CSS3, SVG, Node.js, graph algorithms, natural language processing, data visualization, responsive design.
